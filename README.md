## 功能

* 发送 `欧非鉴定`，机器人回复两个 0~1000 的随机指数，并按指数高低随机配上一个表情。
* **每日一次，按人计算**：同一个人在任意群聊或私聊中鉴定过，当天在**其他会话**中也不能再鉴定，换群无法刷分。
* 表情可关闭：客户端字体缺少 emoji 字形时，可在插件配置里关掉表情，只保留纯文字。
* 纯本地计算：不依赖任何第三方库、不调用大模型、无需配置 API Key，响应即时。

## 安装

1. 确保你已经安装并运行了 AstrBot。
2. 将此插件的文件夹 `astrbot_plugin_oufei_jianding` 放置在 AstrBot 的 `data/plugins` 目录下。
3. 启动或重启 AstrBot。
4. 在 AstrBot 的 WebUI 插件管理页面中，找到 `欧非鉴定` 插件并启用它。

## 使用方法

在机器人可以接收消息的地方（私聊或群聊）发送：

```
/欧非鉴定
```

别名：`/欧非`、`/oufei`

* **首次鉴定**：机器人回复两项指数与表情。
* **当日再次鉴定**（任一会话）：机器人回复「你今天已经鉴定过了，明天再来吧~」。
* **次日鉴定**：次数在每日 0 点（以 AstrBot 主机本地时区为准）重置。

## 配置

在 WebUI 的插件配置页面可调整：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `use_emoji` | bool | `true` | 是否在结果中使用 emoji。关闭后只输出纯文字，适用于客户端字体缺字形的场景。 |

## 数据存放

鉴定记录保存在：

```
data/plugin_data/astrbot_plugin_oufei_jianding/records.json
```

内容形如 `{"用户ID": "YYYY-MM-DD"}`。写入采用「临时文件 + 原子替换」，不会出现写坏一半的中间状态；超过 31 天的旧记录会自动清理，文件大小有上界。

> 从旧版本（1.0.x，记录写在 `data/oufei_jianding/records.json`）升级时，插件会在首次启动时自动迁移记录，并把旧文件改名为 `records.json.migrated`。
